# Stenaline Wifi Scanner

Scan for wifi vouchers and register using an unused voucher.

## Usage

Connect to the `Internet@Sea` network and wait a few minutes. Then run:

```sh
go install github.com/gwillem/stena@latest
stena scan
stena login <voucher>
```
